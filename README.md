#Регистратор#
Программа для регистрации и настройки кассы Терминал-ФА.

**Описание**
Эта программа предназначена для регистрации и настройки кассовых аппаратов Терминал-ФА, подготовки заявлений на регистарцию и актов ввода в эксплуатацию. Так же программа позволяет выполнять настройки открытия/закрытия смены, синхронизировать время с ПК, читать отчеты о регистрации и настраивать параметры ОФД. Установка осуществляется через скачивание и запуск установочного файла, который хранится в облаке.

**Требования**
Операционная система: Windows
Необходимое программное обеспечение: .NET Framework 4.8 и выше, пакет Office

**Установка**
Перейдите по ссылке для скачивания установочного файла:
https://s3-kassa.komtet.ru/komtetkassa-support/Регистратор/Setup_Registrator_2.1.2.msi

Скачайте файл Setup_Registrator_2.1.2.msi

Запустите скачанный файл и следуйте инструкциям мастера установки.

После завершения установки программа будет доступна в меню приложений или на рабочем столе.

**Обновление**
Для обновления программы повторите шаги скачивания и установки нового файла из облака.
